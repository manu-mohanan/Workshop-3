# plans/

Two format examples for demoing the `plan-scope-reviewer` subagent and
practicing the four-question checklist:

- `example-plan-in-scope.md` — a normal, well-scoped plan.
- `example-plan-out-of-scope-demo.md` — the same kind of plan, with notes
  on how to deliberately produce an out-of-scope diff against it so the
  subagent has something real to flag.

These are placeholders for the demo only. In the actual 20–70 minute
hands-on block, attendees review **real plans from their own developers**
— never these samples.
